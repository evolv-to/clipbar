# Capture and retention

ClipBar stores up to 500 recent items in a local SQLite database and owned PNG
files. Managed directories use mode 0700 and files use 0600. This limits access
by other local accounts; it is not application-level encryption and does not
protect against software running as you or an administrator.

The Mac watcher skips concealed, transient and autogenerated pasteboard types
before reading their payloads. An app that omits these markers can still expose
a copied secret. The menu's **Pause clipboard capture** skips new local copies
without capturing them later when resumed. It does not stop incoming sync.
Restarting the watcher does not capture the clipboard that already existed.

LAN and Tailscale require [explicit pairing](pairing.md). iCloud Drive is a
separate, default-off channel. Enabling it stores each device's latest snapshot,
including image data, in iCloud Drive. Disabling it leaves existing snapshots
there. Removing a peer does not erase history already received by that peer.

## Delete retained content

Stop both launch agents first (quitting a KeepAlive app alone restarts it):

```sh
launchctl unload ~/Library/LaunchAgents/app.clipbar.ClipBar.plist
launchctl unload ~/Library/LaunchAgents/app.clipbar.clipd.plist
```

From the repository, deliberately select a scope and confirm permanent deletion:

```sh
uv run --directory clipd python clipd.py purge --local --confirm
# Optional, separately: removes owned ClipBar snapshots in this iCloud directory.
uv run --directory clipd python clipd.py purge --cloud --confirm
```

The command refuses to run while the current app or daemon holds its profile
lock. Local deletion clears database rows, checkpoints/truncates the SQLite WAL,
vacuums the database and removes validated owned image files. Pairing keys and
approved devices are preserved. Unsafe links and unrelated files are left alone.
This is logical deletion, not a promise of forensic erasure from SSDs, backups
or provider retention. Other devices retain their own history. Disable cloud
sync on all participants before cloud cleanup, or another device may write a new
snapshot. Logs are separate and are not removed by these commands.

Restart the services you want after maintenance:

```sh
launchctl load ~/Library/LaunchAgents/app.clipbar.clipd.plist
launchctl load ~/Library/LaunchAgents/app.clipbar.ClipBar.plist
```

## Logs and development

The installer creates private logs under `~/.config/clipd/logs/`. Current event
logs omit clipboard payloads but may include device names, network addresses,
paths and errors. Older `/tmp` logs are preserved and may contain copied text.
Review logs before sharing; source publication checks do not sanitize runtime
files or backups.

For isolated tests, set `CLIPBAR_CONFIG_DIR` on both the app and daemon. The
daemon also accepts `CLIPBAR_BIND_HOST=127.0.0.1`, `CLIPBAR_PORT=0` and
`CLIPBAR_NO_DISCOVERY=1`. `CLIPBAR_PASTEBOARD_NAME` selects a named test pasteboard
on both components; omit it only for an intentional physical paste test. Use
synthetic content and leave cloud sync off in test profiles.
