# Security reports

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/evolv-to/clipbar/security/advisories/new).
Include the affected revision, impact, and reproduction using synthetic data.
Do not attach real clipboard history, credentials, device configuration or raw
logs containing private information. Keep exploit details out of public issues
until a coordinated fix is available.

See the README's privacy section for current runtime limitations and
[the publication guide](docs/publication.md) for contributor safeguards.
